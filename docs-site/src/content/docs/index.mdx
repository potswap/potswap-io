## Install

No install step. Node 20+ and one command:

<Code code="npx -y @potswap_io/mcp" lang="bash" />

Add it to Claude Desktop, Claude Code or Cursor in a minute. Without a key the server runs read-only (search, quotes, trending lists, points of any wallet). Add `SOLANA_PRIVATE_KEY` or `SOLANA_KEYPAIR_PATH`, or let the agent run `wallet_create` and fund the address it prints.
